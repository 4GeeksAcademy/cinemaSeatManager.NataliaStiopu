🎯 VALIDACIONES DETALLADAS
════════════════════════════════════════════════════════════════════════════

RESERVAR ASIENTO:

  ✓ ¿Es disponible?
  ✓ ¿Nombre no vacío?
  → Marcar como reservado si todo es válido

  ✓ ¿Existe el asiento?
  ✓ ¿No está ya ocupado?
  → Marcar como ocupado si es válido

LIBERAR ASIENTO:
  ✓ ¿Existe el asiento?
  ✓ ¿No está disponible?
  → Marcar como disponible si es válido
